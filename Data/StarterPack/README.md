# Стартовый пакет данных

Это демонстрационные данные для проверки импорта и интерфейса. `DEMO-1` и `DEMO-2` не являются статьями закона, а шаблоны маркировки не описывают реальные статусы.

Замените пять файлов оригинальными данными перед использованием по назначению. Приложение сохранит их в App Group после импорта через вкладку «Словари».
